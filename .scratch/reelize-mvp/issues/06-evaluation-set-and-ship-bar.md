# 06 — Evaluation set and ship bar

Type: grilling
Status: open

## Question

The destination says shipped = 3+ real videos through the CLI and the driver would genuinely post the output. Decide what that concretely means:

1. **The video set**: which 3+ videos prove the MVP? Must include the driver's own content — [03 moment scoring](03-moment-scoring-prototype.md) validated the rubric only on an agent-chosen podcast; whether it holds on the driver's niche is the open risk.
2. **The numeric bar**: 03's smoke test scored 8/10 would-post. What rate on what count counts as shipped (e.g. ≥6/10 per video across all 3)?
3. **The mechanism**: 03's review page (embedded players + 🔥/🤔/🗑 verdicts + JSON export) worked well — does it become the standing evaluation step after each pipeline run, and does the pipeline emit it per job?
