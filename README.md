# Reelize — landing page

One link in, a month of shorts out.

Paste a YouTube link → AI transcribes it with timecodes → AI scores the moments worth clipping → you get a pack of vertical 9:16 clips ready for Reels, TikTok and Shorts.

## What this repo is

A single-file marketing landing page. No build step, no dependencies.

```
index.html   # everything: markup, CSS, JS
```

Open it locally:

```bash
open index.html
```

## Deploy

Published with GitHub Pages from the `main` branch, root folder.
